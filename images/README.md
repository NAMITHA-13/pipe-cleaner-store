# images/

Put product photos, your logo and the hero image here.

Suggested names:
- `logo.svg` (or .png)
- `hero.jpg`
- one file per product, named after its id: `sunny-sunflower.jpg`, `tulip-trio.jpg`, ...

Then set `image: "images/sunny-sunflower.jpg"` for that product in `js/products.js`.
Square photos (e.g. 800x800, compressed to under ~200 KB) look best in the grid.
